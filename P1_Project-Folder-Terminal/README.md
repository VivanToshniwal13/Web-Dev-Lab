# P1 — Project folder and terminal navigation
**Aim:** Create a workspace and navigate it using terminal commands.

```bash
mkdir web-portfolio
cd web-portfolio
pwd
ls -la
mkdir assets css js
touch index.html css/style.css README.md
find . -maxdepth 2 -type f
```
**Result:** A project directory with assets, css, js and starter files. `pwd` shows the current directory; `ls` lists files.
